# Touchline — focused midterm completion plan

## Audience and scope
For college students and soccer fans, Touchline lets them practice tactical soccer decisions and inspect animated explanations of soccer rules.

## Focus feature 1 — Tactical decisions
- [x] Display a pitch and accept a text instruction.
- [x] Parse explicit jersey references such as `num 7 run to the box` without choosing a different shirt.
- [x] Animate a named off-ball runner independently of the ball.
- [ ] Student manually checks that the browser animation matches the instruction in the latest version.

## Focus feature 2 — Soccer rules demonstration
- [x] Select offside/onside and view a passer, receiver, defenders and animated ball.
- [x] Show other rules such as throw-in, corner, goal kick and penalty.
- [ ] Student confirms visuals and captions are accurate in Chrome.
