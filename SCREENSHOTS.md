# Before / After Screenshots

For the midterm submission, attach these images after testing in a browser:

1. **Before:** screenshot of initial decision feedback showing points only, taken from the `main` version before the improvement.
2. **After:** screenshot showing the selected action, points and written explanation on the improvement branch (or merged `main`).
3. **Final summary:** screenshot of the completed review showing score and per-round feedback.
4. **GitHub evidence:** screenshots of [Issue #2](https://github.com/QuocAn1909/before-the-pass/issues/2) and its linked PR.

Screenshot files can go into a `screenshots/` folder. This document is a checklist, **not** a claim that screenshots have been captured.
